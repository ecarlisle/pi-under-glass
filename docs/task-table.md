# AGENTS.md's task table

**Use when:** Modifying AGENTS.md's task table

Keep the table small: its rows enter context even when their guides are not needed.

- Use a short trigger and a descriptive guide link. Put procedures in the guide.
- Use plain Markdown links, not eager `@`-imports.
- Copy each guide's authoritative **Use when:** text into its table row. Update both together.
- Read every guide matching the task; a match does not exclude other rows.
- Aim for eight rows or fewer. Consolidate related tasks before adding more.
- If growth requires another index, route to it by topic so overlapping tasks remain discoverable. Add it only when needed.
